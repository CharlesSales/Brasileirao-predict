# 🔮 Previsão de Resultados do Brasileirão com Machine Learning

Este projeto aplica **Machine Learning** para prever os resultados de partidas do Campeonato Brasileiro Série A com base no desempenho recente das equipes. Embora ainda em desenvolvimento, o modelo já atinge uma taxa de acerto de aproximadamente 50%.

## 📊 Funcionalidades

- Leitura de dados do Brasileirão
- Extração de estatísticas dos últimos 5 jogos por time
- Treinamento do modelo com RandomForestClassifier
- Previsão dos resultados da Rodada 24 do Brasileirão de 2024 como teste do modelo

## 📈 Resultados

- Taxa de acerto da rodada: 50%
- Rodada de teste: Rodada 24 do Brasileirão
- Gráfico de performance: Matriz de Confusão
